# ОБЩЕЕ ОПИСАНИЕ
Проект "Chitay Gorod" представляет собой набор автоматизированных тестов для проверки функциональности веб-приложения
интернет-магазина книг "Читай-город", реализованных с использованием Selenium и pytest.

Целью данного проекта является обеспечение качества программного обеспечения за счет выполнения как пользовательских 
интерфейсных (UI) тестов, так и тестов на уровне API.

Для визуализации отчетов применяется Allure.

## ЗАПУСК ТЕСТОВ И ФОРМИРОВАНИЯ ОТЧЕТА

Для запуска тестов необходимо:
1. Клонировать проект:
    git clone https://github.com/gridneva1nv/Chitay-gorod.git
2. Установить все зависимости:
    pip install -r requirements.txt
3. Запустить тесты и сохранить результаты их выполнения в папку allure-results:
     python -m pytest --alluredir allure-results
4. Формирование и последующий просмотр отчета: 
    allure serve allure-results

## СТРУКТУРА ПРОЕКТА
* pages/: Директория, содержащая паттерны PageObject. Включает:
  * main_page.py: Класс и методы для работы с главной страницей сайта
  * book_page.py: Класс и методы для работы со страницей книги
  * cart_page.py: Класс и методы для работы со страницей корзины
* test/: Директория, содержащая тестовые файлы. Включает:
  * test_ui.py: Тесты для проверки пользовательского интерфейса, включая проверку доступности страницы, взаимодействие 
  с элементами на странице, добавление книг в корзину через UI и очистку корзины, выполнение поиска книг по фразе  
  * test_api.py: Тесты для проверки функциональности API, таких как получение информации о книгах, добавление книг в 
    корзину, проверка состояния корзины и очистка корзины, выполнение поиска книг по фразе.
* requirements.txt: Содержит список зависимостей проекта.
* conftest.py: Содержит фикстуры для инициализации браузера, формирования заголовков с токеном и параметров поиска.
* config.py: Содержит  настройки окружения (URL, пути к файлам, тестовые данные).
